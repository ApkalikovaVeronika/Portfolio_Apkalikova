## Использование AI

В процессе работы использовался **ChatGPT**.

### Задача AI

AI-помощник использовался для исследования требований задания, прототипирования структуры страницы, реализации HTML/CSS/JavaScript и последующего ревью соответствия требованиям.

### Существенный запрос

> «Проверь одностраничное портфолио на соответствие требованиям задания по веб-дизайну: Mobile First, адаптивность, обязательный JavaScript-функционал, информация о себе, образование, опыт, навыки, проекты, footer с указанием AI и JavaScript, README с документацией AI.»

### Результат проверки

Проверка показала, что исходной версии не хватало обязательного footer с информацией об AI и JavaScript, структурированных блоков резюме, полноценной документации README и явной Mobile First-структуры CSS.

### Что исправлено самостоятельно

После проверки самостоятельно были приняты и внесены следующие решения:

- сохранена экспериментальная визуальная концепция портфолио;
- сохранены исходные изображения проектов без редизайна;
- убраны ненужные контакты и информация о практике;
- определены актуальные данные об образовании, курсе, профессии и навыках;
- информационные блоки адаптированы под общий визуальный язык сайта;
- мобильная версия сделана базовой, а desktop-стили вынесены в `@media (min-width: 801px)`;
- проверена структура файлов для публикации через GitHub Pages.

AI не использовался для передачи персональных данных, токенов или паролей.
